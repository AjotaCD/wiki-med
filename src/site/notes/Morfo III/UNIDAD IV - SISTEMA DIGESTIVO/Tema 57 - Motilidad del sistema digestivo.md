El sistema digestivo tiene una precisión mecanica esencial, el sistema digestivo es una fábrica sincronizada y altamente automatizada que utiliza sensores quimicos y nerviosos.
# Masticación y trituración
Inicialmente, se tiene que masticar y triturar la comida antes de ser digerida, esto empieza con la presencia del bolo en la boca, aqui hay una automatización del sistema masticatorio, pues cuando el bolo entra en la boca, por reflejo la mandibula cae, este estiramiento activa al huso neuromuscular para que por reflejo los dientes aplasten el bolo alimenticio y se repita el ciclo.
## Deglución
Esta fase es 100% voluntaria, los musculos genioglosos elevan el vértice de la lengua mientras el estilogloso y el hiogloso ahuevan la lengua y la proyectan para que el bolo alimenticio se arrastrado hacia las faringes. A partir de aqui el bolo baja por la faringe mediante peristaltismo.
El peristaltismo es la forma que tiene el esofago de movilizar la comida. Que en resumen funciona mediante la contracción del musculo esófagico proximal al bolo y la relajación de las paredes esofagicas distal al bolo.
# Estómago
Al llegar al estomago, un reflejo vasovagal reduce el tono muscular, para almacenar el bolo sin aumentar la presión. Posteriormente ese activa la bomba pilorica, el esfinter pilorico permanece semi-cerrado, permitiendo solo el paso de liquidos, y una onda anular en el cuerpo avanza hacia al antro, luego ocurre una violenta retropulsión que mezcla el quimo mediante movimientos.

# Intestino delgado
aqui hay dos tipos de movimientos para mover el quimo
## Segmentación
Trocean y desmenuzan el quimo para maximizar el contacto con la mucosa.
## Peristaltismo
Empuja el alimento a 1cm/minuto, esto es tan lento para permitir que el quimo esté en contacto con la superficie intestinal el mayor tiempo posible para la absorción de nutrientes.
# El complejo motor migratorio
Este limpia el intestino durante los periodos interdigestivos, se libera una hormona llamada Motilina que desencadena muchas contracciones potentes que barren los restos, bacterias y secreciones hacia el intestino grueso
# Intestino grueso
Este tiene un diseño muy distinto, formado por "Sacos", tres bandas llamadas tenias colicas. Si contracción amasa el tejido de un lado a otro hasta reabsorber todo el liquido y dejar nada mas que una masa semisolida.

# Defecación
En primera, hay un reflejo gastrocolico que se activa mediante la distensión del estómago y duodeno tras el ingreso del comida, esto desecadena los movimientos colonicos para liberar espacio en el intestino. Aqui el movimiento empuja las heces hacia el recto, provocando una distención rectal y una relajación refleja del esfinter anal interno para la expulsión.
